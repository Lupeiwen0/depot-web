## 包管理工具

- 使用 pnpm 作为包管理工具

## api 接口 jest 单元测试

- 所有的 api 接口都必须有对应的单元测试功能
- 每次更改动 api 接口都必须执行单元测试

## 代码检查

- 每次代码改动完成之后 都要执行 ts 类型错误检查

## 数据操作

- 所有页面中涉及到数据交互，必须采用 api 接口方式，绝对不能在页面中操作数据库
- 页面内 api 接口调用应使用 lib/api-utils 中的公共方法
- 如果是客户端组件，直接使用 fetch 请求即可

## 页面组件库

- 优先使用 shadcn/ui 组件库

## 状态管理 zustand

- 公共状态管理优先使用 zustand

## 国际化

- 代码修改完成之后记得同步更新涉及到的国际化内容

## stripe 支付

- api 版本试用的 2025-12-15.clover
- 代码应符合 对一个版本的数据结构

## 分页列表处理

- 最后一页删一条数据后当前页面没数据了 应该返回前一页
- 当前在第 n 页，做了排序，或商品编辑列表刷新，页码不应该重置
